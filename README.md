# Habitgame — QUEST FORGE II

現実の5分の課題を、モンスターと挑む冒険に変えるブラウザゲームです。

- 10個の課題、各5分のタイマー、残り時間に応じた攻撃
- 3地域・複数フロア、仲間の編成・スキル・育成・進化
- ガチャ、卵ドロップ、BGM・SE・時間の音声案内
- 課題の続きから再開、ブラウザ保存、バックアップの書き出し・読み込み

個人の課題やプレイデータはブラウザ内に保存され、リポジトリには含まれません。

## 開発と公開

Python 3、Node.jsのみを使用します。外部パッケージのインストールは不要です。

```sh
python3 build.py
node test-engine.cjs
node test-app.cjs
python3 -m http.server 8000 --directory docs
```

GitHub Pagesの公開元は `main` ブランチの `/docs` です。
ゲームを更新したら `python3 build.py` を実行し、`src` と `docs` を一緒にコミットします。

## データの引き継ぎ

ローカル版とGitHub Pages版はブラウザの保存領域が異なります。
ローカル版の「記録・設定」→「バックアップを保存」で保存し、
公開版の「読み込む」からバックアップの内容を貼り付けてください。

## サウンド

BGMと効果音はWeb Audioで生成します。音声案内は端末の日本語音声を使用します。
音の開始には画面内のボタン操作が必要です。画面ロック中の音声は端末やブラウザにより停止する場合があります。

## 画像

3地域のボス背景は、このゲーム用に作成したオリジナル画像です。
モンスターやUIの画像・音源に既存ゲームの素材を使用していません。
