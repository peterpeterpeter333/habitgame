# Habitgame — QUEST FORGE IV

現実の課題で、未知の世界を一歩ずつ切り開くブラウザRPG。

- 通常モードは1課題5分、集中モードは1課題30分。課題数は各モードで1〜100個に変更でき、入力と進捗は別々に保存
- 最初に3体から相棒を1体だけ選択。幼体を含む全5形態。未来の姿・名前は進化後まで非表示
- 攻略に応じて道が開く地図。未踏の地域・未遭遇の仲間・進化先は表示しない
- 8地域・48ダンジョン＋各地域最奥の降臨8種。進むほど難易度が上がる
- 240系統・384形態：相棒3、一般種141、精鋭種60、召喚限定36。全系統に入手経路あり
- 一般種はLv20・進化なし、精鋭はLv50・2形態、召喚限定はLv80・3形態、相棒はLv100・5形態
- 道中の卵65%、ボスの卵100%。素材・卵・コインは獲得時点で保存
- 召喚は5石。銀55%・金35%・虹10%。未知の名前を隠した個別提供割合を表示
- 魔法石は最初のダンジョンの初クリア5個、他の通常ダンジョンの初クリア1個、降臨の初クリア1個。通常・降臨とも再クリア0個
- 攻撃の予備動作・着弾・撃破・卵、召喚、相棒の目覚めの専用演出。スキップ対応
- 短い断片を拾う旅の記録。長いストーリー会話なし
- 敵→味方5枠→HP→5分タイマーと完了ボタンの専用戦闘画面

画像はこのゲーム用のオリジナル。既存ゲームの画像・音源を使用していません。
個人の課題とプレイ情報はブラウザ内に保存され、サーバーへ送信しません。課金なし。

## 開発・公開

Python 3とNode.js。外部パッケージ不要。

```sh
python3 build.py
node test-engine.cjs
node test-app.cjs
node test-task-continuation.cjs
node test-focus-mode.cjs
node test-flexible-tasks.cjs
node test-gem-rewards.cjs
node test-battle-fx.cjs
node test-sound-fx.cjs
python3 -m http.server 8000 --directory docs
```

GitHub Pagesは `main` の `/docs` から公開。更新時は生成したdocsもコミットします。
単一HTMLは `python3 build-standalone.py /出力先/quest-forge.html`。

## 保存とリセット

ユーザーの明示的なリセット依頼に従い、v4は新しい旅として開始します。
`quest-forge-v4` に保存し、起動時に旧版の保存キー（v1・v2/v3バックアップ）を削除します。
v4のバックアップのみ読み込み可能。以後の更新でv4を自動リセットしません。
相棒・全所持品は「課題のリセット」では消えません。

## v4.4.0の演出

属性ごとに異なる衝撃輪・斬撃と、スキル6種のカットインを追加。仲間の攻撃に合わせて敵HPが減り、撃破とボス踏破には専用の光・破片・効果音が入ります。演出はスキップでき、動きを減らす設定では揺れや回転を抑えます。
拠点の外周まで金の装飾、天球の輪、光の柱を広げ、神殿のような枠を追加しました。戦闘のダメージ計算・時間切れ判定・報酬と保存形式は維持します。

## v4.3.0のグラフィック

月明かりの拠点背景と現在の相棒を置いたロビーを追加。霧、光の粒、相棒の息づかいを軽いCSSアニメーションで表現します。
召喚の星の門も専用イラストに変更し、メニュー、カード、素材、戦闘の枠と配色を統一。スマートフォンと動きを減らす設定に対応しています。
未発見の土地・仲間・進化先の表示ルール、戦闘、課題、報酬、保存データは維持します。
新規背景は組み込みimage_genで制作し、`assets/luminous-sanctuary-v1.png` と `assets/summon-gate-v1.png` に保存。

## v4.2.1の変更

魔法石の報酬を初クリアのみに変更。最初の道は5個、それ以外の通常・降臨はそれぞれ初クリア1個、再クリア0個です。
通常と降臨の攻略記録は別に判定します。獲得済みの石や攻略記録は維持し、過去分の再付与は行いません。

## v4.2.0の追加

課題数を両モードで1〜100個に変更できます。新規プレイの初期値は通常1課題・集中2課題です。
既存の10課題や途中の進捗は維持し、更新時に勝手に減らしません。
一巡後は「同じ課題で続ける」で編集を挟まず再開できます。「課題を変更して続ける」では内容と個数を変更できます。
敵・味方のHP、スキル、戦利品を維持し、準備中はタイマーを停止。再開時に報酬を重複して付けません。

## v4.1.0の追加

課題の準備画面または出発前に、集中モード（1課題30分×2課題）を選べます。
1つ完了すると攻撃し、次の課題は新たに30分から開始。時間内の達成で反撃は受けません。
2つ終えてもHPが残っていれば、次の2課題を用意して同じ戦闘を続行できます。
毎分の音声案内・残り時間の表示は30分に対応し、攻撃の最大威力は通常モードと同じです。
通常の課題・進捗、仲間、素材、冒険中の保存データを維持します。

## v4.0.2の修正

制限時間内の課題達成では敵からの反撃を受けません。敵が攻撃するのは時間切れのときだけです。
旧版の冒険を途中から再開しても同じルールを適用し、敵の行動カウント表示を攻撃条件の案内に変更しました。

## v4.0.1の修正

10個の課題を終えてもHPが残っている冒険は敗北扱いにせず、課題の準備待ちにします。
次の10課題を設定して、敵・味方HP、スキル、報酬を保ったまま続行できます。準備中の時間は停止します。
v4.0.0の課題上限で誤って敗北した保存データだけを準備待ちへ復元します。獲得済み報酬は再付与しません。

## 検証

ゲームルール、全系統の入手経路、成長区分、素材進化、初回の攻略、全48道の解放、
ガチャ確率境界、期限境界、オフライン精算、冒険の継続をテスト。
画面側は未発見情報の非表示、選択、戦闘、報酬、召喚、秘密の進化を確認。
長期の難易度とドロップ体験は、実プレイの感触に応じて調整する余地があります。

## 制作資料

`art-prompts.json` は画像生成の最終プロンプト群。組み込みimagegenで制作しました。
`expansion-plan.json` は追加種と絵の対応、`companion-rects.json` は相棒画像の表示範囲。
`research.html` はv3制作時のパズドラ調査記録で、v4の現行仕様書ではありません。

BGM/SEはWeb Audio、時間案内は端末の日本語音声。画面ロック中は端末により止まります。
