# Habitgame — QUEST FORGE III

現実の5分の課題を、モンスターと挑む冒険に変えるブラウザゲームです。

- 10個の課題、各5分のタイマー、残り時間に応じた攻撃。中断した課題の次から再開
- 専用の縦型戦闘画面：敵と背景 → 味方5枠 → HP → 課題・タイマー・完了ボタン
- オリジナル24系統・72形態、5属性、6種類のスキル、リーダー効果
- 経験値・強化合成・重複合成・2段階進化。素材は各ダンジョンで収集
- 5地域の通常・降臨、敵の行動カウント、怒り、属性相性、モンスタードロップ
- 5魔法石でガチャ。銀60%・金30%・虹10%、個別確率はゲーム内に表示
- BGM・SE・時間の音声案内、ブラウザ保存、バックアップの書き出し・読み込み

個人の課題やプレイデータはブラウザ内に保存され、リポジトリには含まれません。

## 開発と公開

Python 3、Node.jsのみ。外部パッケージ不要です。

```sh
python3 build.py
node test-engine.cjs
node test-app.cjs
python3 -m http.server 8000 --directory docs
```

GitHub Pagesの公開元は `main` の `/docs` です。更新時は生成したdocsもコミットします。
任意で `python3 build-standalone.py /出力先/quest-forge.html` を実行すると単一HTML版を作れます。

## データの引き継ぎ

同じ公開URLの旧データは自動移行し、旧状態を別キーに退避します。旧版の戦闘中状態は終了し、課題の再開位置を引き継ぎます。
ローカル版と公開版は保存領域が異なります。「記録」からバックアップを保存し、移行先で読み込んでください。

## 画像・音・調査

72形態とダンジョン背景はこのゲーム用のオリジナル画像です。既存ゲームの画像・音源は使用していません。
BGMと効果音はWeb Audio、時間案内は端末の日本語音声を使います。音の開始にはボタン操作が必要です。
画面ロック中の音声は端末やブラウザにより停止する場合があります。

パズドラの公式情報に基づく分類・進化系統・素材・ドロップの調査と実装への反映範囲は `research.html` を参照してください。
全個体・全レシピを網羅したデータベースではありません。
