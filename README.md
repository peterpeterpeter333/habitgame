# Habitgame — QUEST FORGE IV

現実の5分の課題で、未知の世界を一歩ずつ切り開くブラウザRPG。

- 最初に3体から相棒を1体だけ選択。幼体を含む全5形態。未来の姿・名前は進化後まで非表示
- 攻略に応じて道が開く地図。未踏の地域・未遭遇の仲間・進化先は表示しない
- 8地域・48ダンジョン＋各地域最奥の降臨8種。進むほど難易度が上がる
- 240系統・384形態：相棒3、一般種141、精鋭種60、召喚限定36。全系統に入手経路あり
- 一般種はLv20・進化なし、精鋭はLv50・2形態、召喚限定はLv80・3形態、相棒はLv100・5形態
- 道中の卵65%、ボスの卵100%。素材・卵・コインは獲得時点で保存
- 召喚は5石。銀55%・金35%・虹10%。未知の名前を隠した個別提供割合を表示
- 初踏破2石（最初のダンジョンは5石）、再踏破1石
- 攻撃の予備動作・着弾・撃破・卵、召喚、相棒の目覚めの専用演出。スキップ対応
- 短い断片を拾う旅の記録。長いストーリー会話なし
- 敵→味方5枠→HP→5分タイマーと完了ボタンの専用戦闘画面

画像はこのゲーム用のオリジナル。既存ゲームの画像・音源を使用していません。
個人の課題とプレイ情報はブラウザ内に保存され、サーバーへ送信しません。課金なし。

## 開発・公開

Python 3とNode.js。外部パッケージ不要。

```sh
python3 build.py
node test-engine.cjs
node test-app.cjs
node test-task-continuation.cjs
python3 -m http.server 8000 --directory docs
```

GitHub Pagesは `main` の `/docs` から公開。更新時は生成したdocsもコミットします。
単一HTMLは `python3 build-standalone.py /出力先/quest-forge.html`。

## 保存とリセット

ユーザーの明示的なリセット依頼に従い、v4は新しい旅として開始します。
`quest-forge-v4` に保存し、起動時に旧版の保存キー（v1・v2/v3バックアップ）を削除します。
v4のバックアップのみ読み込み可能。以後の更新でv4を自動リセットしません。
相棒・全所持品は「課題のリセット」では消えません。

## v4.0.1の修正

10個の課題を終えてもHPが残っている冒険は敗北扱いにせず、課題の準備待ちにします。
次の10課題を設定して、敵・味方HP、スキル、報酬を保ったまま続行できます。準備中の時間は停止します。
v4.0.0の課題上限で誤って敗北した保存データだけを準備待ちへ復元します。獲得済み報酬は再付与しません。

## 検証

ゲームルール、全系統の入手経路、成長区分、素材進化、初回の攻略、全48道の解放、
ガチャ確率境界、期限境界、オフライン精算、冒険の継続をテスト。
画面側は未発見情報の非表示、選択、戦闘、報酬、召喚、秘密の進化を確認。
長期の難易度とドロップ体験は、実プレイの感触に応じて調整する余地があります。

## 制作資料

`art-prompts.json` は画像生成の最終プロンプト群。組み込みimagegenで制作しました。
`expansion-plan.json` は追加種と絵の対応、`companion-rects.json` は相棒画像の表示範囲。
`research.html` はv3制作時のパズドラ調査記録で、v4の現行仕様書ではありません。

BGM/SEはWeb Audio、時間案内は端末の日本語音声。画面ロック中は端末により止まります。
